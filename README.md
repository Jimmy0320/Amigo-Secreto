Proyecto: Amigo Secreto
Este proyecto es un juego interactivo de Amigo Secreto desarrollado en HTML, CSS y JavaScript. Permite a los usuarios agregar nombres a una lista y realizar un sorteo aleatorio para elegir al amigo secreto. Incluye un botón para reiniciar el juego y volver a empezar fácilmente.

Características
•	Agregar nombres a la lista de amigos.
•	Visualizar en pantalla todos los amigos agregados.
•	Sortear aleatoriamente un amigo de la lista.
•	Mostrar el resultado del sorteo en tiempo real.
•	Reiniciar el juego limpiando la lista y los resultados.
•	Interfaz amigable y visualmente atractiva.

Cómo ejecutar el proyecto
1.	Clona este repositorio o descarga el ZIP.
2.	git clone https://github.com/tuusuario/amigo-secreto.git
3.	Abre el archivo index.html en tu navegador favorito.
4.	¡Empieza a jugar agregando nombres y sorteando tu amigo secreto!
